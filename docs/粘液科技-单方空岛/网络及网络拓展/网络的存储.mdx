要存储物品，有多种方式....

下面结构展示了3种在网络中存储物品的方式...

<StructureViewer name="NTW_Storgae" />

其实可以归为两类方式：量子存储，网络单元。

### 量子存储

量子存储有两种方块：量子存储和网络抽屉。它们都需要使用网络监视器。

<ItemIcon item="NTW_MONITOR" size={50} />

量子储存可以升级，最高14级，有140T的存储空间，<Term tip="真的用不完吗？">你这辈子都用不完！</Term>还有一种高级量子储存，可以自由设定存储上限。

唯一的缺点是只能存储一种，比较常用于使用量子纠缠奇点来放入终极堆叠里使用

<ItemIcon item="NTW_EXPANSION_CARGO_STORAGE_UNIT_13"/>

还有网络抽屉，这个机器能提供32~35种物品的存储，从256到21亿的单种类物品数量！可惜没有140T的存储空间，也不能被量子纠缠奇点绑定，这导致其多用于怀旧空岛。

他们都需要被网络监视器标记...像上面那个结构一样，才能在网格种看到...

### 网络单元

优点是，这个机器的存储优先级低于量子存储，并且是一个大箱子的存储空间，这使得其可以用来存储杂物，而且它不需要网络监视器。

缺点是，这个机器会容纳超出量子存储存储能力的物品，这导致其经常被网络自动合成机塞满.....并且在部分服务器以性能问题的理由封禁。

所以在纯网络环境里用的很少。

还有就是，AE使用网络交换机，无法读取到这个里面的物品，也没法使用它存储物品。
