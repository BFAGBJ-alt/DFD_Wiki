# 引言

应用能源 - Applied Energistics2, Mod圈物流最高的山最长的河，广泛出现在各大科技整合包。

而粘液科技亦有自己的AE2：SlimeAE。(下文简称AE)

本分支将着重于其用法教学，问题答疑，以及部分使用特性的实现。

## 开始

要开始AE的游玩,你至少应该在原版粘液科技中，发展到[能源与电力]篇章。本附属开头的机器就需要使用电力。你至少应该有512J/s左右的发电量。

开头，我们应当制作一个[充能器](/docs/粘液科技-单方空岛/应用能源/物品/充能器)。我们将使用他获取基础的3种石英和3种粉。
