## 网络工具

<Columns left={75}>
<div>

```text
/sf give @s network_tool
```

### 用途

右键可查看整个AE网络的各个网络元件；Shift右键可将大部分AE设备拆卸为掉落物形式。

网络工具也可以用 [下界石英扳手](#下界石英扳手) 代替赛特斯石英扳手合成，配方其余部分相同。

### 合成配方

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'enhanced_crafting_table',
  pattern: [
    'AB ',
    'CD ',
    '   ',
  ],
  materials: {

    B: {id: 'quartz_glass'},
    C: {id: 'printed_calculation_processor'},
    D: {id: 'chest'},
  },
  result: {id: 'network_tool'},
}} />

</div>
