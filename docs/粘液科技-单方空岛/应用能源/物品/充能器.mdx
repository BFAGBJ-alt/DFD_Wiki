### 用途

用于制造赛特斯石英以及其他AE材料。

### 合成配方

需要：增强型工作台

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'enhanced_crafting_table',
  pattern: [
    'IFI',
    'I  ',
    'IFI',
  ],
  materials: {
    I: {id: 'iron_ingot'},
    F: {id: 'ferrosilicon'},
  },
  result: {id: 'me_charger'},
}} />
