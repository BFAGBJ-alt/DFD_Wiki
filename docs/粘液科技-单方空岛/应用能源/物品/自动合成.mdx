自动合成的流程是：样板终端编码样板 → 样板放进ME接口 → 分子装配室在接口旁执行合成。

每个AE网络中，每个合成任务最多只会使用 16384 个合成设备。

## 分子装配室

<Columns left={75}>
<div>

```text
/sf give @s molecular_assembler
```

### 用途

在自动合成中充当粘液合成台；需要放在ME接口旁边，且只能用于AE的自动合成。

### 合成配方

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'enhanced_crafting_table',
  pattern: [
    'ABA',
    'CDE',
    'ABA',
  ],
  materials: {
    A: {id: 'iron_ingot'},
    B: {id: 'glass'},
    C: {id: 'annihilation_core'},
    D: {id: 'craft_table'},
    E: {id: 'formation_core'},
  },
  result: {id: 'molecular_assembler'},
}} />

</div>
