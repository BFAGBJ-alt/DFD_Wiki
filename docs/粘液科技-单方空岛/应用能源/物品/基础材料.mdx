基础材料主要由**矿物粉碎机**（SlimeFun 机器）和**充能器**获得。充能器每秒消耗 256J，配方耗电按时间计算（如 2s = 512J）。

矿石/石英在矿物粉碎机中粉碎为粉的比例均为 1:1。

## 下界石英粉

<Columns left={75}>
<div>

```text
/sf give @s quartz_dust
```

### 用途

可在充能器中继续升级为赛特斯石英粉。

### 合成配方

需要：矿物粉碎机

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'ore_crusher',
  pattern: [
    'Q  ',
    '   ',
    '   ',
  ],
  materials: {
    Q: {id: 'quartz'},
  },
  result: {id: 'quartz_dust'},
}} />

</div>

<div>

<ItemIcon item="quartz_dust" size={100} />

</div>

</Columns>
