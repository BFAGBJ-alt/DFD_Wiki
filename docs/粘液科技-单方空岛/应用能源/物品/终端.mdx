终端是访问AE网络的入口：合成、规划、样板与无线绑定都由不同终端完成。

## ME终端

<Columns left={75}>
<div>

```text
/sf give @s me_terminal
```

### 用途

管理ME网络内的物品。

### 合成配方

需要：增强型工作台

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'enhanced_crafting_table',
  pattern: [
    'GCP',
    'L  ',
    '   ',
  ],
  materials: {
    G: {id: 'quartz_glass'},
    C: {id: 'formation_core'},
    P: {id: 'annihilation_core'},
    L: {id: 'logic_processor'},
  },
  result: {id: 'me_terminal'},
}} />

</div>

<div>

<BlockDisplay item="me_terminal" size={100} />

</div>

</Columns>

## ME合成终端

<Columns left={75}>
<div>

```text
/sf give @s me_crafting_terminal
```

### 用途

在ME终端的基础上提供合成功能，可直接在终端内合成物品。

### 合成配方

    '   ',
