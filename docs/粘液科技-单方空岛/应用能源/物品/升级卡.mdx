升级卡插在ME机器中，分别提供加速、自动补货、红石信号与设置复制等功能。

## 基础卡

<Columns left={75}>
<div>

```text
/sf give @s basic_card
```

### 用途

最基础的升级卡，主要作为其他升级卡的合成材料。

### 合成配方

<RecipeViewer recipe={{
  type: 'shaped',
  machine: 'enhanced_crafting_table',
  pattern: [
    'AB ',
    'CDB',
    'AB ',
  ],
  materials: {
    A: {id: 'gold_ingot'},
    B: {id: 'iron_ingot'},
    C: {id: 'redstone'},
    D: {id: 'calculation_processor'},
  },
  result: {id: 'basic_card', count: 2},
}} />

</div>

<div>

<ItemIcon item="basic_card" size={100} />

</div>

</Columns>
