## 我为什么进不去地狱/末地了？

自查：
 - 是否清空了某个维度的方块？
 - 是否破坏/盖住了某个维度的基岩？

如果是，找管理处理。

> 或者如果你有足够的耐心....可以从别人家的地狱飞到自己的地狱

## 如何给予他人身份？

```text
/is coop <player>
```
给与玩家协作者/合作伙伴身份。

```text
/is trust <player>
```
给予玩家可信者身份。

:::danger[警告]
请*务必*不要开放容器\破坏权限给游客身份或是给予陌生人身份。

**权限只给可信的人！**
:::

:::tip[提示]
如果要寻求帮助，`/is warps`寻找已开商店的大佬。

他们通常毕业，对你岛上的东西没兴趣。
:::

### 可能的误区

**身份≠权限**，每一种身份的权限需要进入岛屿页面(`/is panel`),在岛屿权限中设置。

## 如何邀请他人/退出或解散岛屿？

### 解散当前岛屿

```text
/is disband
```
适用于你是岛主，受到他人邀请的情况。

需要**岛主**身份。
:::danger[将军，请三思！]
此操作**无法撤销**，你**确定**真的要解散自己的岛屿吗？
:::
### 退出当前岛屿

```text
/is leave
```
适用于你是被邀请入他人岛屿的情况。

### 邀请他人进入岛屿

```text
/is invite <player>
```
适用于你需要邀请其他人入岛的情况

需要岛主/管理员身份身份。
