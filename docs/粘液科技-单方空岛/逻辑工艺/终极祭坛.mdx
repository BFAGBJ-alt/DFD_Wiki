# 踏入终极！

在漫长的挂机后，你终于到达了这一阶段。

终极祭坛是这一阶段需要制作的多方块结构，它可以用来激活宏激光发射器，物质量化重塑器，属性量化增幅器<Spoiler>(孩子们，我被ban了)</Spoiler>。  

## 逻辑核心的生产

在做终极祭坛之前，你需要先做一个东西：反概念物质。毕竟祭坛需要几千个逻辑核心，你不可能指望用机器去做。

<ItemIcon item="logitech_antimass" size={50} />

前面几个逻辑核心必须要用到量子纠缠奇点,在终极概念凝聚者中制作。<Spoiler>(不然光靠一组一组输入要输入到猴年马月啊0.o)</Spoiler>

做好之后，找一块风水宝地，把他放下来（离你机器远一点，或者干脆放在空中），反概念物质会尝试向四周蔓延，然后变成逻辑核心。准备一把无法破坏的效率锄头，挖掉逻辑核心，大概能获得解决2w个。

如果你怕给你机器吞了，那么做个冷殇的`反概念物质同化机`。产的慢是慢了点，起码没有风险。

## 机制

该多方块结构没有配方时间，取而代之的是特殊的机制。

### 特殊要求

位于二级祭坛上的机器，四周的激光不可被方块阻挡。

这意味着二级祭坛机器只有上面能用于物流传输。
