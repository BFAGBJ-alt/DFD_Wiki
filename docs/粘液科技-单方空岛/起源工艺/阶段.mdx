起源工艺目前有两个版本：一个是单方空岛的旧版，一个是测试服的最新1.3.1(以下统称为新版)。

教程将使用旧版的发育流程来编写。新版内容内容则会在扩展部分进行讲解（毕竟这玩意也就加了后期的东西）

## 发育阶段

流程可以用机器框架来划定，也可以用粘液书中的顺序来划定。

机器框架有以下等级：原始  魂钢 -> 耀金 -> 极限

或者按照粘液书中的基础机器 -> 维度工艺 -> 高级机器 -> 挑战线。
