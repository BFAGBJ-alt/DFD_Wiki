### 方式一：直接输入尺寸创建（推荐新手） 

玩家在墙上放好空的物品展示框，排列成想要的形状，然后：

#### 第一步：获取图片直链

把想要展示的图片（PNG/JPG/GIF）上传到 https://img.remit.ee/free-image-hosting 复制链接，拿到一个以 https:// 开头的直链。

#### 第二步：输入创建命令

在聊天栏输入：

```text
/if create <名称> <图片链接> <宽度> <高度> 
```

最大宽高：`3 x 3`
 
#### 第三步：放置地图

命令执行后，背包里会出现对应数量的地图物品（如果选了 `combined` 就是一个组合物品）。走到展示框前，右键把地图放进框里，图片就会显示出来。如果图片*较大*（超过 1×1），建议命令末尾加上 `combined`

```text
/if create <名称> <图片链接> <宽度> <高度> combined
```

这样你只会拿到 一个组合物品，右键一次就能自动填充所有展示框，拆掉时也会整体回收，不用一个一个放。


### 方式二：先选框，再创建（更精准）

如果展示框已经摆好但不确定尺寸，可以用选择模式：

#### 第一步：进入选择模式

```text
/if select
```

#### 第二步：逐个选择展示框

对着每个要填充的展示框右键点击，选中的框会高亮。全部选完后，潜行（按住`Shift`）再右键一次，确认选择。

#### 第三步：创建并自动填充

```text
/if create <名称> <图片链接> selection
```

图片会直接填入你选中的所有展示框，不需要手动放置
