### 第一步：获取选区工具

默认的选区工具是**木锄**！！！！

### 第二步：用木锄标记两个对角点

1.走到你想圈的区域一角，用木锄左键点击一个方块，设为起点。
2.走到对角位置，用木锄右键点击方块，设为终点。

系统会自动生成一个以这两个点为体对角线的长方体区域，并用粒子效果标出边界。

### 第三步：查看选区大小和费用

在创建之前，先输入以下命令确认选区是否符合预期：

```text
/res select size
```

这条命令会显示你所选区域的尺寸以及创建所需的费用

每一个方块创建时需要1金币

### 第四步：创建领地

确认无误后，输入：

```text
/res create <领地名>
```
